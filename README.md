# IDM Lite ⚡

**بديل خفيف لـ Internet Download Manager** — تحميل متعدد الاتصالات مع استئناف، التقاط روابط من الحافظة، واجهة حديثة، وتكامل مع المتصفح.

كله مكتوب بـ Python القياسي فقط (بدون أي مكتبات خارجية وقت التشغيل) — عشان الـ exe يشتغل على أي ويندوز من غير تعقيدات.

---

## ✨ المميزات

| الميزة | الوصف |
|---|---|
| **تحميل متعدد الاتصالات** | يقسّم الملف لقطاعات (حتى 32 اتصال) ويحمّلها بالتوازي |
| **استئناف (Resume)** | بيكمّل من نفس البايت بالظبط — حتى بعد قفل الجهاز |
| **استئناف تلقائي** | بيكمّل التحميلات الناقصة لما تفتح البرنامج أو لما يرجع النت |
| **يعمل في الخلفية** | أيقونة في System Tray + Continues التحميل لما تقفل النافذة |
| **بدء تلقائي مع ويندوز** | option في الإعدادات يخلي البرنامج يشتغل مع الجهاز |
| **ثيم داكن وفاتح** | تبديل فوري من زر ☀/☾ في الهيدر |
| **واجهة حديثة** | شريط جانبي للتصنيفات، شريط أدوات بالأيقونات، بحث، شريط تقدم متدرج |
| **نافذة كتالوج التحميل** | لما يمسك رابط: حجم الملف + مكان الحفظ + زر Download/Cancel |
| **لوحة تفاصيل** | نسبة %, شريط تقدم, السرعة, الوقت المتبقي,和支持 الاستئناف, Parts Info |
| **إعادة محاولة تلقائية** | 5 محاولات مع تصاعد تدريفي |
| **تحديد السرعة** | حد عام بالـ KB/s |
| **التقاط من الحافظة** | بيقترح تحميل أي رابط ملف تنسخه |
| **تكامل مع المتصفح** | إضافة Chrome/Edge/Firefox تسلّم التحميلات للبرنامج |
| **تصنيفات** | Image / Music / Video / Apps / Document / Compressed / Other |
| **قائمة محفوظة** | بيسترجع التحميلات لما تفتح البرنامج مرة تانية |

## 🚀 التشغيل السريع

### إن كان عندك الـ exe جاهز
شغّل `IDM Lite.exe` — زي أي برنامج تاني. مفيش تنصيب، مفيش متطلبات، ومفيش نافذة كونسول.

> الـ exe ملف واحد بيفك نفسه في `%LOCALAPPDATA%\IDMLite` أول مرة ويفتح البرنامج من there.
> الإعدادات والتحميلات بتتحفظ في `%APPDATA%\IDMLite` (مش في مجلد فك الضغط).

### يعمل في الخلفية
- زر **Background** في شريط الأدوات أو زر **×** (لو "Close to tray" مفعّل) بيخفي النافذة
  والبرنامج بيفضل يحمّل في الـ System Tray.
- من قائمة الـ Tray: إظهار البرنامج، إضافة رابط، تشغيل/إيقاف/استئناف، **Start with Windows**، خروج.
- دبل كليك على أيقونة الـ Tray بيرجّع النافذة.

### بدء التشغيل مع ويندوز
`Settings → Background & resuming → Start with Windows` (أو من قائمة الـ Tray).
بيكتب في `HKCU\Software\Microsoft\Windows\CurrentVersion\Run` — مفيش صلاحيات إدارية.

### لو عايز تبنيه بنفسك على ويندوز
```bat
1. نزّل Python 3.10+ من python.org ( ticking "Add to PATH")
2. شغّل build_windows.bat
3. هتلاقي الملف في dist\IDM Lite.exe
```

### تشغيل الكود مباشرة
```bat
python main.py
```

## 🧩 إضافة المتصفح (عشان البرنامج "يلقط" تحميلات المتصفح)

البرنامج بيشغّل **بروكسي صغير محلي** على `http://127.0.0.1:21123` — أي رابط المتصفح بيحاول ينزّله بيوصّله للبرنامج.

**Chrome / Edge:**
1. افتح `chrome://extensions`
2. فعّل **Developer mode** (أعلى يمين)
3. اضغط **Load unpacked** واختر مجلد `browser_extension`
4. خلاص — أي تحميل في المتصفح هيتحوّل لـ IDM Lite

**Firefox:**
1. افتح `about:debugging#/runtime/this-firefox`
2. **Load Temporary Add-on** → اختار `browser_extension/manifest.json`

## 🖱️ طريقة الاستخدام

**الشريط الجانبي:** All / Image / Music / Video / Apps / Document / Compressed / Other / Finished / Unfinished
(الأرقام على اليمين = عدد الملفات في كل تصنيف).

**شريط الأدوات:**
| الزر | الوظيفة |
|---|---|
| **Add URL** | يفتح نافذة الكتالوج (رابط + مجلد + اسم + حجم الملف) |
| **Start Queue** | تشغيل المحدد |
| **Pause Queue** | إيقاف مؤقت |
| **Stop All** | إيقاف كل التحميلات |
| **Resume All** | استئناف كل التحميلات الناقصة |
| **Settings** | الإعدادات |
| **Background** | إخفاء النافذة والاستمرار في الخلفية |

**في اللستة:**
- كليك على الصف = تحديد، `Ctrl` = تحديد متعدد، `Shift` = نطاق
- كليك على عنوان العمود = ترتيب
- دبل كليك = لوحة التفاصيل
- كليك يمين = قائمة (تشغيل/إيقاف/استئناف/فتح المجلد/نسخ الرابط/حذف)

**نافذة الكتالوج (Add download):** بتظهر-size الملف تلقائياً، وتختار المجلد والاسم، وبعدين **Download** أو **Cancel**.

**لوحة التفاصيل:** تبويب **Info** (الحجم، المنزّل، السرعة، الوقت المتبقي، هل الاستئناف مدعوم) +
**Part Info** (كل قطاع في الجدول) + شريط تقدم متدرج + زر Pause.

**اختصارات:** `Ctrl+N` إضافة · `Ctrl+F` بحث · `Enter` تفاصيل · `Delete` حذف · `F5` تحديث

## ⚙️ الإعدادات

`Settings` (من الشريط الجانبي أو زر الترس):

- **Downloads:** الاتصالات لكل ملف، التحميلات المتوازية، حد السرعة، المحاولات، المهلة، مجلد الحفظ
- **Appearance:** الثيم (فاتح/داكن)
- **Background & resuming:** تشغيل في الـ Tray، إخفاء النافذة عند الإغلاق، البدء مع ويندوز، الاستئناف التلقائي عند بدء التشغيل، الاستئناف عند رجوع النت
- **Notifications:** مراقبة الحافظة، التنبيه الصوتي، التنبيه البصري، حفظ القائمة

الإعدادات والتحميلات بتتحفظ في:
```
%APPDATA%\IDMLite\config.json
%APPDATA%\IDMLite\tasks.json
```

## 🔧 إزاي الـ exe الواحد اتبنى

البرنامج نفسه بايثون (PyInstaller)، بس الملف النهائي **مش** PyInstaller onefile مباشر:

1. `PyInstaller --onedir` بيطلع مجلد `IDM Lite/` فيه البرنامج وكل الـ DLLs.
2. `tools/launcher.c` (مكتوب بـ C ومُصرَّف بـ mingw-w64) هو **مشغّل Win32 أصلي**:
   - بيحمل التطبيق جوه كـ payload جوّه الـ exe نفسه (ملف واحد).
   - أول تشغيل بيفكه في `%LOCALAPPDATA%\IDMLite\app`.
   - بيشغّله بـ `CREATE_NO_WINDOW` — يعني **مفيش نافذة كونسول** خالص.
3. `tools/pack_launcher.py` بيضمّ الـ payload للـ stub.

**ليه مش PyInstaller onefile مباشر؟** لأن CPython محتاج كونسول حقيقي يعمل له attach للـ
standard streams، ونسخ `--windowed` بتفشل في كتير من البيئات. المشغّل الأصلي ده
بيحل المشكلة دي من غير ما يبيّن أي نافذة.
